新建工作区

只允许字母、数字、点、下划线、短横线；只创建目录；第一次进入时新建运行。 workspaces/<name>/

首次使用

按顺序完成五步，训练按钮会在缺项时带你回到对应位置。

  1. 工作区先新建一个工作区；配置、缓存、runs、logs 都会放进去。
  2. 模型文件在训练设置页填写 DiT、文本编码器目录、VAE；三个字段都可探测。
  3. 数据集到数据集页扫描任意本地目录，路径会写回当前 profile。
  4. 缓存构建 latent 索引（index.json）；样图预览可再编码 preview.safetensors，不影响训练。
  5. 训练选择 profile，预检通过后开始训练。

新建运行

新运行得到自己的一份 runs/<run>/config.yaml；模型与数据集路径在训练设置里填。
